# 华夏器道 — 中国古代传统文化与古瓷数字化研鉴空间

> 器以载道 · 格物致知 · 独立学术与数字文博专栏

## 核心工程简介

本工程为独立研究者自主设计与研发的中国古代传统文化与古陶瓷 3D 数字化交互研鉴空间。综合运用 Three.js WebGL 三维实时渲染、PBR 双层物理釉面、金丝铁线动态开片着色器、纯前端色彩直方图与高频纹理开片智能识别算法，打造集“3D互动研学、AI智能识瓷、陶瓷通史、制瓷工序、传统色谱、文人四艺”于一体的高端文博空间。

## 模块清单

- `主代码.html`：数字化研鉴主程序入口
- `css/style.css`：宋韵水墨定制样式、3D控制面板与激光扫描动画
- `js/three-scene.js`：Three.js 7大古代经典器型建模、PBR物理釉面、金丝铁线动态贴图生成器
- `js/ai-recognition.js`：纯前端图像特征工程（色彩直方图、开片纹理检测、WebRTC摄像头扫描、古陶瓷知识库引擎）
- `js/data.js`：华夏陶瓷通史、天工核心工序、东方传统色谱、典藏名品学术数据库
- `js/i18n.js`：中英文双语即时切换国际化支持
- `js/app.js`：全局事件调度、通史时间轴联动、色卡复制、通用模态窗控制器
- `images/`：高清古陶瓷摄影与水墨素材资源
