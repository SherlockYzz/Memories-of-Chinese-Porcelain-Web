# 慧眼识瓷 — 宋代官瓷数字化体验平台

> **器以载道，AI 赋能非遗技艺数字化传承**  
> 🌐 **在线体验地址（GitHub Pages）**：[https://sherlockyzz.github.io/Memories-of-Chinese-Porcelain-Web/](https://sherlockyzz.github.io/Memories-of-Chinese-Porcelain-Web/)

## 一、项目简介

**「慧眼识瓷」** 是由**河南大学仝瓷记忆团队**（于子倬、邢雅静等同学）开发的宋代官瓷数字化体验平台。平台运用现代数字科技手段（**3D 建模、WebGL 实时渲染、AR 增强现实、AI 智能识瓷**），将千年宋代官瓷技艺进行数字化还原与交互呈现，让大众能够沉浸式了解与体验中国传统官瓷文化。

---

## 二、技术栈

- **前端核心**：`HTML5` + `CSS3` + `JavaScript (ES6+)`
- **3D 展馆渲染**：`Three.js` / `WebGL`
- **视觉与图标**：`Font Awesome 6` + 中国传统水墨宋韵自定义样式
- **智能交互**：AI 瓷器识别与 AR 展品预览

---

## 三、使用说明

1. **在线直接访问**：点击上方 [GitHub Pages 在线体验链接](https://sherlockyzz.github.io/Memories-of-Chinese-Porcelain-Web/) 即可直接在浏览器中浏览。
2. **本地运行**：克隆仓库后，在浏览器中打开 `index.html` 或 `仝瓷记忆网页/主代码.html` 即可。
3. **运行环境建议**：
   - 推荐使用 `Chrome`、`Edge` 等现代浏览器；
   - 3D 展馆功能需浏览器开启 `WebGL` 硬件加速支持；
   - AR 交互功能需后端服务支持及移动端摄像头权限。
